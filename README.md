Project 5: FIFA 23 Player Performance Analysis

Dataset: FIFA 23 Complete Player Dataset (Kaggle)
Introduction:
Football clubs rely on data analytics for player scouting. This project analyzes player attributes,
salaries, and performance metrics to identify top talents.
Key Questions to Answer:
1. Which players have the highest market value and why?
2. Is there a correlation between age and player performance?
3. Which nationalities dominate in FIFA rankings?
4. What attributes (speed, shooting, passing) contribute most to player value?
   
Tasks to Perform:
● Clean and preprocess FIFA dataset.
● Plot distributions (histograms, box plots).
● Build a regression model to predict player value.

Deliverables:
● Jupyter Notebook with full analysis.
● Predictive model for player valuation.
● Report with scouting insights.
